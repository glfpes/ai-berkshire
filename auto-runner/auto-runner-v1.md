## 波动率均值回归短线波段策略 v1

### 是什么

一套**选股 + 择时**的短线波段策略。目标很具体：**找到 1 只「日波动够大、PE 合理、近 60 天在一个区间里反复来回波动（而不是一路下跌）」的股票，为它算出一条合理价格的 baseline（价值中枢），当价格跌到 baseline 之下时分批低吸，赚到 3%~5% 微利就清仓，其余时间空仓等待。**

一句话：**在会波动、跌不穿、又不贵的股票上，低买高卖赚波动的钱。**

### 为什么

* **要波动**：波段策略靠振幅吃饭。没有波动（死水股）就没有低吸和止盈的空间。SK 海力士这类高弹性、强周期标的，情绪易过度摆动，能反复提供入场机会。
* **要合理 PE**：PE 是「地基体检」。PE 过高（泡沫）意味着一旦杀估值，波动会变成单边下跌，波段变套牢；PE 为负或异常（亏损/垃圾股）说明基本面在恶化，随时可能崩塌。合理 PE 是「跌下去还能弹回来」的前提。
* **必须是「震荡」而非「单边下跌」**：这是本策略的**生死线**。均值回归的假设是「价格会回到中枢」。如果一只票近 60 天是一路阴跌，那所谓的「低吸」只是在下跌半途接飞刀，中枢本身在不断下移，越低吸亏越多。所以必须先排除单边下跌的票。
* **要 baseline**：baseline 是「便宜」的量化标尺。没有基准，「低吸」就是凭感觉。有了 baseline，才能纪律化地只在价格 < baseline 时才动手。
* **专业验证**：符合量化中的 **Mean Reversion（均值回归）/ 统计套利** 逻辑——用高胜率的小幅盈利实现复利，用严格空仓和止损规避单边行情的深套。

### 怎么做

策略分为四道关卡，**全部通过才是候选标的**，任何一关不过直接淘汰：

#### 第一关：PE 体检（合理估值）

* PE 必须为**正**（剔除亏损/垃圾股）。
* PE 落在**合理区间**（默认 5 ≤ trailingPE ≤ 60；具体阈值可按行业调整，周期股放宽）。
* PE 过高 → 泡沫风险，一票否决；PE 为负 → 基本面恶化，一票否决。

#### 第二关：波动体检（够不够波）

* 用近 60 天日收益率算**日波动率**与**年化波动率**，并计算 **ATR（真实波幅）** 占股价的比例。
* 日波动率太低（默认年化 < 25%）→ 波动不足，没有波段空间，淘汰。
* 波动越大越好，但需配合第三关确认是「来回波动」而非「往下崩」。

#### 第三关：趋势体检（是震荡，不是单边下跌）——生死线

用三个互补指标共同确认「近 60 天是常规区间震荡，而非单边下跌」：

1. **区间累计涨跌**：60 天首尾涨跌幅不能过度为负（默认 > -15%）。一路跌 20%+ 的直接淘汰。
2. **趋势斜率**：对收盘价做线性回归，斜率不能显著向下（默认年化斜率 > -20%）。
3. **穿越次数 / 震荡度**：统计收盘价穿越其均值（中枢）的次数。反复穿越 = 在中枢上下来回（健康震荡）；几乎不穿越且一直在均值下方 = 单边下跌（淘汰）。

> 核心区分：**震荡**的价格围绕中枢上下摆动、频繁穿越均线；**单边下跌**的价格持续位于下行均线下方、极少回穿。

#### 第四关：计算 baseline（合理价格中枢）

baseline 的目标是回答「相对最近，当前价便不便宜」。**注意：纯 60 天算术均值不适合当 baseline**——在趋势市（尤其急跌）里，60 天前的旧高价会把均值拖偏，得出「假便宜」信号，诱使你在下跌半途接飞刀（如 SK海力士近 60 天腰斩，纯均值仍显示当前价「便宜 -22%」，实为陷阱）。

因此 baseline 采用**近期加权中枢**：

* 主锚：**EMA20（20 日指数移动平均）**——近期价格权重更高，趋势市里紧跟真实中枢，不被旧价拖偏。
* 辅以**中位数**抗极值污染。
* 公式：`baseline = 0.7 × EMA20 + 0.3 × 中位数`。
* 报告同时展示**纯 60 天均值**作为对照，方便观察趋势市里均值失真的程度。

综合得到 baseline 后，再计算当前价相对 baseline 的**折价/溢价**：

* 当前价 **< baseline 且折价达到入场阈值**（默认低于 baseline 2% 以上；因 EMA 更贴近现价，阈值较均值方案下调）→ **可考虑分批低吸**。
* 当前价 **≥ baseline** → 不便宜，**空仓等待**，不追高。

#### 执行纪律（通过四关且价格在 baseline 下方后）

1. **分批建仓**低吸，不一次打满。
2. 硬性**止盈 3%~5%**，到点清仓不贪。
3. 设**同等严格的止损红线**，跌破立即离场（防止「震荡」演变为「单边下跌」时深套）。
4. 未达良机时**坚定空仓**。

### 配套工具

`python3 strategy_screen.py <股票代号>`（如 `python3 strategy_screen.py SKHY`）

输入一个美股代号，工具自动拉取近 60 天成交数据 + PE，跑完上述四关，输出一份简要数字报告，并直接给出**该不该买**的判断（BUY / WAIT / REJECT）与理由。数据层由 `market_data.py` 提供。

## 实现说明（当前版本 v1）

### 文件架构

```
auto-runner/
├── auto-runner-v1.md      本文档：策略思路 + 实现说明
├── market_data.py         数据层：拉取美股 60 天成交数据 + PE
└── strategy_screen.py     策略层：四关体检 + 买卖判断（依赖 market_data.py）
```

分层设计：`market_data.py` 只负责「取数」，`strategy_screen.py` 只负责「判断」。取数逻辑变化不影响策略逻辑，反之亦然。

### 版本演进（做了哪些改动）

| 阶段 | 改动 | 原因 |
|------|------|------|
| 初版 | 只有 `market_data.py`，能取 60 天 OHLCV | 满足「查成交数据 + PE」的基础需求 |
| 加策略 | 新增 `strategy_screen.py`，实现四关体检 | 把「找会波动、跌不穿、又不贵的票」的想法量化 |
| 改 baseline | baseline 从 `(均值+中位+MA20)/3` 改为 `0.7×EMA20 + 0.3×中位数` | 纯均值在急跌市被 60 天前旧高价拖偏，产生「假便宜」信号（如 SK海力士腰斩仍显示便宜 -22%）。EMA 近期加权紧跟真实中枢，消除接飞刀陷阱 |
| 调阈值 | 入场折价阈值 3% → 2% | EMA 比均值更贴近现价，折价数字天然变小，需下调阈值否则 BUY 信号过难触发 |

### 关键计算（有什么计算）

所有阈值都是 `strategy_screen.py` 顶部的常量，可直接改：

```python
PE_MIN = 5.0            # PE 下限
PE_MAX = 60.0           # PE 上限
VOL_ANNUAL_MIN = 0.25   # 年化波动率下限 25%
DRAWDOWN_MIN = -15.0    # 60 天累计涨跌下限 -15%
SLOPE_ANNUAL_MIN = -20.0 # 年化回归斜率下限 -20%
CROSS_RATIO_MIN = 0.08  # 穿越中枢频率下限（穿越次数/交易日）
EMA_SPAN = 20           # baseline EMA 周期
BASELINE_EMA_W = 0.7    # baseline 中 EMA 权重
ENTRY_DISCOUNT = 2.0    # 入场折价阈值 2%
```

**① 波动率**（第二关）
- 日收益率：`r_i = close_i / close_{i-1} - 1`
- 日波动率 = 日收益率的样本标准差（除以 n-1）
- 年化波动率 = 日波动率 × √252
- ATR% = 平均真实波幅 / 平均收盘价 × 100；真实波幅 `TR = max(high-low, |high-前收|, |low-前收|)`

**② 趋势（震荡 vs 单边下跌，第三关）** — 三指标 + 一条组合规则
- 区间累计涨跌 `pct_period = (末收 / 首收 - 1) × 100`
- 回归斜率：对收盘价序列做最小二乘（x=0..n-1），斜率年化 = `slope × 252 / 平均价 × 100`
- 穿越中枢次数：统计收盘价穿越其 60 天均值的次数；`cross_ratio = 穿越次数 / 交易日数`
- **单边下跌组合规则**（同时满足则判死）：斜率向下 且 60%+ 时间在均值下方 且 累计为负 且 穿越频率 < 0.12

**③ baseline（第四关）**
- `EMA20`：指数移动平均，`k = 2/(20+1)`，`e_i = close_i × k + e_{i-1} × (1-k)`
- `baseline = 0.7 × EMA20 + 0.3 × 中位数`
- 折价 `discount = (当前价 - baseline) / baseline × 100`（负数 = 便宜）
- `cheap = discount ≤ -2%`

**④ 综合判断**
- 任一硬关卡（PE / 趋势 / 波动）不过 → `REJECT`
- 三关全过 + `cheap` → `BUY`
- 三关全过 + 不够便宜 → `WAIT`

### 数据来源（怎么产出）

数据全部来自 **Yahoo Finance**，通过 `curl` 调用（绕过 Python SSL 问题）：

| 数据 | 接口 | 鉴权 | 说明 |
|------|------|------|------|
| 成交数据 OHLCV | `v8/finance/chart/{ticker}` | 无需 | 收盘/最高/最低/成交量；`turnover=close×volume` 为**估算成交额** |
| PE / 估值 | `v10/finance/quoteSummary/{ticker}` | 需 cookie + crumb | trailingPE / forwardPE / PB / 市值 / EPS；脚本内自动完成 `fc.yahoo.com 拿 cookie → 换 crumb → 带鉴权请求` 握手，crumb 进程内缓存 |

**已知数据局限**：
- Yahoo 对**非美股（韩股 .KS / 港股 .HK 等）常不返回 PE**，此时第一关会判 REJECT（理由标注「无 PE 数据」），需人工另查 PE 补充。
- `turnover` 是 `close×volume` 估算，非交易所口径真实成交额。
- baseline 是基于**近 60 天价格**的技术中枢，回答「相对最近便不便宜」，**不回答「绝对值不值」**（内在价值需另做基本面研究）。
- 报告输出里价格符号硬编码为 `$`，对非美元标的（如韩股韩元）数值正确但币种符号不准。

### 怎么使用

**基本用法**
```bash
cd auto-runner
python3 strategy_screen.py SKHY          # 单标的体检报告 + 该不该买
python3 strategy_screen.py NVDA --days 60 # 指定回溯交易日（默认 60）
python3 strategy_screen.py MU --json      # 输出结构化 JSON，供程序调用
```

**只取数据不做判断**
```bash
python3 market_data.py NVDA TSLA AAPL --days 60  # 多标的成交概况 + PE
python3 market_data.py NVDA --json               # 完整 JSON
```

**作为库调用**
```python
from market_data import get_market_data       # 取数
from strategy_screen import screen             # 判断

r = screen("MU", days=60)
print(r["verdict"])   # "BUY" / "WAIT" / "REJECT"
print(r["rationale"]) # 判断理由
print(r["gates"]["baseline"])  # baseline 明细
```

**报告字段速查**
- `verdict`：`BUY`（可低吸）/ `WAIT`（空仓等回落）/ `REJECT`（不做）
- `gates.pe / volatility / trend / baseline`：四关各自的 `pass` 与 `reason`
- `gates.baseline.baseline`：合理价格中枢；`.ema20 / .median / .mean`：三种中枢对照（`mean` 是纯均值，趋势市里若明显高于 `ema20` 即为失真警示）
- `gates.baseline.discount_pct`：当前价相对 baseline 的折价（负=便宜）；`.cheap`：是否达到入场阈值
- `stats`：成交概况（区间涨跌、日均量、波动率、区间高低）

**BUY 后的执行纪律**（工具会在报告里提示）
> 分批低吸，止盈 3%~5% 清仓，跌破 baseline 下方 8% 止损。

**调参**：直接修改 `strategy_screen.py` 顶部常量即可（如周期股放宽 `PE_MAX`、低波动市场下调 `VOL_ANNUAL_MIN`）。
